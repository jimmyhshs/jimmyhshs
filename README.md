## 소개

안녕하세요. AI.SW를 전공하고 있는 **오지미**입니다.

현재 대학에서 프로그래밍 기초부터 자료구조, 웹 프로그래밍, 인공지능 등  
소프트웨어 개발에 필요한 다양한 분야를 단계적으로 학습하고 있습니다.

새로운 기술을 배우고 직접 구현해보는 과정을 중요하게 생각하며,  
수업에서 배운 내용을 개인 프로젝트와 GitHub에 기록하면서 개발 역량을 쌓아가고 있습니다.

특히 **인공지능과 소프트웨어 개발의 결합**에 관심이 있으며,  
사용자에게 실제로 도움이 되는 서비스를 만드는 개발자로 성장하고 싶습니다.

## 개발 철학

> **배운 것을 기록하고, 기록한 것을 구현하며, 구현한 것을 개선합니다.**

처음부터 완벽한 코드를 작성하는 것보다  
직접 구현하고 발생한 문제를 분석하면서 더 나은 방법을 찾아가는 과정을 중요하게 생각합니다.

작은 프로젝트라도 직접 완성해보는 경험을 통해  
프로그래밍 언어뿐만 아니라 문제를 정의하고 해결하는 능력을 함께 키우고 있습니다.
